# 📅 Calendar Payment App

A frontend-only React + Vite application for tracking and visualizing recurring payments on a calendar.

## Features

- **Payment Form** – Add payments with a name, amount, start date, and recurrence type
- **Monthly Calendar View** – See all payment dates highlighted with labels on a calendar grid
- **Year View / Payment List** – Browse all scheduled payment occurrences for a year, grouped by month, with a yearly total
- **Multiple Payments** – Add and manage as many payments as you like
- **Recurrence Types**: One-Time, Weekly, Bi-Weekly, Monthly, Quarterly, Annually

## Tech Stack

- [Vite](https://vite.dev/) + [React](https://react.dev/) (JavaScript)
- Standard CSS (no frameworks)
- No backend required

## Getting Started

```bash
npm install
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

```bash
npm run build
```

The production build will be output to the `dist/` directory.
